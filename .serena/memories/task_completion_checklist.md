# タスク完了時のチェックリスト

1. コードレビュー
   - [ ] Terraformコードのフォーマット確認（`terraform fmt`）
   - [ ] セキュリティ設定の確認
   - [ ] リソース名の命名規則確認
   - [ ] 変数の適切な型定義確認

2. テスト
   - [ ] `terraform plan`でエラーがないことを確認
   - [ ] 新規追加リソースの依存関係確認
   - [ ] Dockerfileのビルドテスト

3. ドキュメント
   - [ ] 変更内容のREADME更新（必要な場合）
   - [ ] 変数の説明追加（新規追加時）
   - [ ] コメントの追加（複雑な設定がある場合）

4. セキュリティ
   - [ ] 機密情報の漏洩がないことを確認
   - [ ] アクセス権限の適切な設定確認
   - [ ] セキュリティグループ設定の確認（AWS）
   - [ ] IAMポリシーの最小権限確認
