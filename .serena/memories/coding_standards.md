# コーディング規約とベストプラクティス

## Terraform
1. リソース名は明確で説明的であること
2. 変数は適切にタイプ定義されること
3. リソースは論理的にモジュール化すること
4. セキュリティに関わる設定は変数化し、値はバージョン管理外で管理すること

## ディレクトリ構造
1. クラウドプロバイダごとに独立したディレクトリを使用
2. 各プロバイダディレクトリ内で関連するリソースをグループ化
3. 共通の変数や設定は最上位のディレクトリに配置

## バージョン管理
1. コミットメッセージは日本語で具体的に記述
2. 機能追加やバグ修正は個別のブランチで実施
3. プルリクエストベースの開発フロー
4. 機密情報は絶対にコミットしない
